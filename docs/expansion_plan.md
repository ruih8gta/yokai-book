# 都道府県別 妖怪マップ 拡張計画（作業メモ・一時ファイル）

京都・栃木と同じ「複数伝承＋出現地ピン＋画像」方式で全県を充実させるためのロードマップ。
1県を追加する手順は **データ追加だけ** で済むようになっている：

1. `src/<id>.json` … 伝承データ（name / place / label / x,y / image / summary / story）
2. `src/img/<id>/*.png` … 各伝承の画像（Geminiで生成）
3. `src/legend_prefectures.json` に県ID（例 `"gunma"`）を追記（図鑑にも全伝承が並ぶ）
4. ピン座標 x,y は `maps/<id>.svg`（viewBox は `maps/_meta.json` 参照）に対し、
   `pref_pins.json` の県bboxと緯度経度から算出（PAD=46）。

> 日本地図からの遷移：京都=kyoto.html / 栃木=tochigi.html は専用ページ。
> それ以外は `pref.html?p=<id>` が `<id>.json` を読み、複数伝承を自動表示する。
